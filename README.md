# Minty Client

Releases of the public Minty Client mod (Fabric, Minecraft 26.3).

**Download the newest version:**
https://github.com/mintymcflir/Minty-client/releases/latest/download/minty-client-public.jar

Put the jar in your `.minecraft/mods` folder (with Fabric Loader and Fabric API). From 10.7 on, Minty updates itself:
open the What's new page in Minty to see updates and turn "Update by itself" on or off.

Every release's `update.json` is signed; Minty refuses any download that isn't.
